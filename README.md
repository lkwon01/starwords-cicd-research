# StarWords

## Cloud Performance Analysis

I enabled AWS CloudFront logging and analyzed request behavior to evaluate cloud performance and reliability.

### Findings
- Average latency: 0.079 seconds
- Client error rate: 42.86%
- Server error rate: 0.00%

### Interpretation
The platform showed low latency and no server-side failures, indicating strong reliability of the cloud-based deployment. The 4xx responses were client-side access/request issues rather than infrastructure instability.
